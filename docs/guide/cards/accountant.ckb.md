# ژمێریار — کارتی خێرا

یەک لاپەڕە بۆ ئەو کەسەی پارە ڕێک ڕادەگرێت.

## چی دەتوانی بکەی

- دابینکەران: زیادکردن، دەستکاری، دانانی نرخیان، پارەدانیان، ڕاستکردنەوەی قەرزی ئێمە، تۆمارکردنی
  کەمکردنەوەی قەرز، نووسینی باڵانسی سەرەتایی
- کڕیاران: بینینی هەموویان، وەرگرتنی پارەدان، تۆمارکردنی قەرز، نووسینی باڵانسی سەرەتایی
- کەرەستەکان: دانانی نرخی کڕین و فرۆشتنی مانگانە
- نرخی ئاڵوگۆڕی گشتی
- هەموو ڕاپۆرتێک، مێژووی هەمووان، نرخی کڕین و قازانج

## هەموو بەیانییەک

**ڕێکخستنەکان → سیستەم → نرخی نوێ** — دیناری ئەمڕۆ بۆ هەر دۆلارێک. ئەگەر نرخی دابینکەرێک
گۆڕاوە، لەسەر پرۆفایلی خۆی دابنێ ("دانانی نرخی ئاڵوگۆڕی کۆمپانیا"): کڕین لەو دابینکەرە نرخی خۆی بەکار دەهێنێت،
نەک هی بازاڕ.

## پارەدان بە دابینکەر

کۆمپانیا → **تۆمارکردنی پارەدان**. ئەوەی ماوە بۆت پڕ دەکرێتەوە، بەو دراوەی پێی یەکلا دەکرێتەوە.
هێڵی ژێر بڕەکە دەنوێنێت حیسابیان دوای پاشەکەوتکردن چی دەڵێت. بەستنەوەی پارەدان بە کڕینێک پێویست
نییە — کڕینی کۆنترین خۆی یەکەم دەدرێتەوە. تەنها کاتێک بەستنەوەی بکە کە کاغەزی دابینکەر خۆی
دەیکات.

## نرخەکان

کەرەستە → **نرخەکانی &lt;مانگ&gt;**: نرخی کڕین و نرخی فرۆشتن بۆ ئەو مانگ. فرۆشتن یان کڕین نرخی
خۆی لەو مانگە دەبات کە بەرواری تێدایە، بۆیە دانانی نرخی ئەم مانگ هەرگیز بەڵگەنامەکانی مانگی
پێشوو نانووسێتەوە. هەموو کەرەستەیەکی چالاک پێویستی بە نرخی ئەم مانگە هەیە.

## ڕاستکردنەوەکان

هیچ شت لە جێی خۆی دەستکاری نەکرێت. پارە بە تۆمارێکی تر ڕاست دەکرێتەوە:

- بە دابینکەری هەڵە، یان بڕی هەڵە درا → تۆمارێکی پێچەوانە لەسەر حیسابەکە، لەگەڵ تێبینییەک کە
  دەڵێت چی ڕوویداوە.
- دابینکەر لەسەر داشکان یان گەڕاندنەوە ڕێک دەکەوێت → **تۆمارکردنی کەمکردنەوەی قەرز**.
- ژمارەیەک کە لە ڕۆژی دەستپێکردندا هەڵە بوو → **ڕاستکردنەوەی قەرزی ئێمە**، لەگەڵ تێبینییەک کە ناوی
  کاغەزەکە دەبات.

هەر یەکێک لەمانە لە دەفتەری حیسابەکە و لە مێژوودا دەردەکەوێت بە ناوی تۆ، باڵانسی کۆن و نوێ.
بەو شێوەیە پرسیارێک لەسەر باڵانسێک ساڵێک دواتر وەڵام دەدرێتەوە.

## کۆتایی مانگ

**ڕاپۆرتەکان → فرۆشتن، کڕینەکان، قازانج، قەرزی کڕیاران، قەرزی ئێمە.** قەرزی کڕیاران و قەرزی
ئێمە بە گەورەترین قەرز یەکەم ڕیز دەکرێن؛ هەر ژمارەیەک بە هەردوو دراو دەردەکەوێت بەو نرخەی
دروستی کردووە. کاتێک ژمارەکانی مانگ ڕێک کەوتن، لە بەڕێوەبەر داوا بکە **ماوە داخراوە هەتا**
بگوێزەرەوە بۆ ڕۆژی کۆتایی مانگ — دوای ئەوە هیچ شتێک کە بەرواری تێدایە ناجوڵێت.

## لێککردنەوەی ڕۆژانە

**ڕاپۆرتەکان → لێککردنەوەی ڕۆژانەی نەقد**: هەر کارمەندێک چەند دەبێت بدات، بۆ هەر دراوێک، بۆ
ئەو ڕۆژ. ئەوە دەژمێرێت کە تۆماری کردووە، نەک ئەوەی سندوق دەڵێت — جیاوازییەکە بابەتی گفتوگۆیە.

---

هەر تۆمارێک کە دەنووسی لە **مێژوو**دایە لەگەڵ باڵانسی پێش و دوای. هیچ شتێک کە تۆ تۆماری دەکەی
دواتر بە نهێنی ناگۆڕدرێت، بە هیچ کەس.
